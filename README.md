# Sunishtha Rajput | Portfolio

Single-page portfolio (HTML, CSS and JavaScript, no build step).

- `index.html` is the whole site (GSAP, ScrollTrigger and Lenis load from a CDN)
- `profile.jpg` is the portrait, `og-image.jpg` is the 1200x630 link-preview card
- `Sunishtha-Rajput-CV-*.pdf` are the two downloadable CVs

To preview locally: `python3 -m http.server 8000`, then open http://localhost:8000
